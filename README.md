## Deploy en produccion

URL: https://TU_URL_DE_VERCEL.vercel.app
Estado: Live

## Proyectos

### restaurante-nextjs (produccion)
Stack: Next.js 15 - TypeScript - Tailwind CSS - App Router
Backend: NestJS

#### Instalacion
cd restaurante-nextjs
npm install
npm run dev

#### Variables de entorno
NEXT_PUBLIC_API_URL=http://localhost:3001

#### Rutas
- /        -> Home
- /mesas   -> Lista de mesas
- /menu    -> Menu de platos
- /carrito -> Carrito de comandas
- /comandas -> Panel de comandas (staff)
- /mesa/[id] -> Detalle de mesa
